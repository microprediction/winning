The photo-finish circuit

The race is a resistor network. Click a runner to delete it.

Twelve runners, two common factors. Node size is win share; wire thickness is the photo-finish tie density between two runners — the conductance of that edge, and exactly the weight in the calibration Jacobian's graph Laplacian. Click a node to remove that runner: the bars show how much more (or less) each survivor gains than the proportional IIA rule predicts. Factor-similar runners gain disproportionately; everything is computed in your browser by the same algorithm the Python package ships, at machine-precision parity.
