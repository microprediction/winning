# Raj et al. 2023 — SNAC-K odor identification errors, n=2,479, distractor choice is the subject

## Citation
Raj R, Hörberg T, Lindroos R, Larsson M, Herman P, Laukka EJ, Olofsson JK. "Odor identification errors
reveal cognitive aspects of age-associated smell loss." *Cognition* 2023;236:105445.
doi:10.1016/j.cognition.2023.105445. (Author list and biblio verified via OpenAlex.)

## Domain and stimuli
Olfaction. SNAC-K cohort, older adults, **n = 2,479** — the largest distractor-level odor
identification analysis found. 16 odors, each with 1 target plus 3 distractors (Sniffin' TOM, the same
instrument as `horberg_2025.md`, which also means the free-then-cued procedure applies).

## Master response set and restricted response sets (nested, overlapping, or a relabelling)
**Fixed 4-alternative cued list.** Inherits the free-then-cued structure of the Sniffin' TOM protocol
(free naming first, 4-AFC on failure), so the same unbounded→4 contraction described in
`horberg_2025.md` is present in this cohort at n≈2,500.

Within the cued phase itself there is no menu variation — one 4-element set per odor.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)
**Which distractor was chosen is the entire subject of the paper — and none of it is deposited.**
This is the most frustrating entry in the directory: a 2,479-subject study whose whole analytic object
is per-descriptor error structure, with no data release. The paper prints model results and error
taxonomies; it does not print a complete 16 × 4 confusion matrix that could be digitized.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)
**Needs library access to read, and a data request to use.**
Two separate asks. Get the PDF via library access first to check whether any table gives a full
per-descriptor breakdown worth digitizing — that is unverified, since the paywall blocked inspection.
Then request the underlying records from SNAC-K, bundled with the `horberg_2025.md` request.

This is the single largest existing corpus of odor-identification distractor choices, so even without a
menu manipulation it is the best available source for fixed-menu choice shares with cognitive
covariates.

## What the authors concluded, quoted verbatim where possible
Not verified verbatim — the paper is paywalled and could not be fetched. From the title and abstract
framing: **odor identification errors are not random**, and the pattern of which incorrect descriptor
is chosen reveals cognitive (semantic/lexical) contributions to age-associated smell loss rather than
purely sensory decline. Treat any more specific attribution as unconfirmed until the PDF is read.
