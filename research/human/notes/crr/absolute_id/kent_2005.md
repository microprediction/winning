## Citation

Kent, C., & Lamberts, K. (2005). An exemplar account of the bow and set-size effects in
absolute identification. *Journal of Experimental Psychology: Learning, Memory, and
Cognition*, 31(2), 289-305. DOI 10.1037/0278-7393.31.2.289. Title, authors and pagination
confirmed via Crossref.

## Domain and stimuli

Absolute identification, reported as using dot separation with set sizes N = 2, 4, 6, 8
and 10 presented to the same participants one after another.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

**Probably nested on the stimulus side; label scheme unverified.** Secondhand via Dodds
et al. (2011), which describes participants performing "absolute identification with dots
varying in separation, using four different set sizes (N = 2, 4, 6, and 8)... set sizes, one
after the other". Whether the smaller sets reuse master labels (as in Dodds) or relabel to
1..N (as in Stewart, Brown & Chater) is **not established**. I have not read this paper.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)

Unknown. Brown, Marley, Donkin & Heathcote (2008) are reported to note that Kent &
Lamberts' error data was not available to them — secondhand and unverified, but if true it
is decisive against cell-level shares existing in print.

Note that the archived Warwick directory for Stewart's 2007 reply (see `stewart_2005.md`)
listed a file `Kent_Lamberts_2005_best_fits.csv`, 650 bytes. At that size it is model fit
statistics, not a confusion matrix. It was never captured by the Wayback Machine either.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Needs library access.** Worth one look because of the N = 2,4,6,8,10 within-subject
range, which would be the widest set-size ladder available if the labels turn out to be
global. Check the label convention first; if it relabels to 1..N, deprioritise.
