## Citation

Adelman, J. S. (2016). Information and Time in Absolute Identification [Data
Collection]. UK Data Service. DOI 10.5255/UKDA-SN-850284.

**Correction to an earlier note in this project:** I initially recorded this as "Adelman,
Stewart & Kent (2009)". That attribution was wrong. It is single-authored and dated 2016.

## Domain and stimuli

Absolute identification. The collection description notes "Participants are presented a
small number (usually 6-10) of such stimuli" and that "participants can usually only perform
perfectly if there are four or fewer stimuli". Tones and dot distances across ten
experiments.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

**Almost certainly no response-set manipulation.** The manipulated variables are stated
as "the influence of the time for which the stimulus is physically available" and "the
decisional or 'thinking' time that is available" — exposure duration and decision time, not
set size. Set size may differ between experiments incidentally, but it is not the design
factor. Unverified at file level, because the files are gated.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)

Ten data files `exp1.txt` through `exp10.txt`, plus six documentation files including two
PDF manuscripts, two .doc ethics forms and two .txt documentation files. Contents unseen.

## Access (a DIRECT url you fetched; open, paywalled, or Wayback-only)

**Gated, registration required.** Landing page fetched, HTTP 200:

    https://reshare.ukdataservice.ac.uk/850284/

Access condition, verbatim from the record: "The Data Collection is available for download to
users registered with the UK Data Service." All files marked "Registered users only
(safeguarded data)." A direct file fetch returns 401.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Probably unusable, low priority.** Raw trial data does exist and registration is free,
so it is cheap to check if someone already has a UK Data Service account. But the documented
manipulation is timing, not response-set size, so expected value is low. Check the two
included manuscripts first — they will state the design without needing the data files.
