## Citation

Petrov, A. (2010). Category rating is based on prototypes and not instances: Evidence
from feedback-dependent context effects. *Journal of Experimental Psychology: Human
Perception and Performance*. Citation as given in the data archive's own readme; note this
is 2010, not 2011, and it is a different paper from Petrov & Anderson (2005).

## Domain and stimuli

Category rating with a feedback manipulation. Two experiments (`fdbk1`, `CRFeedback2`)
plus a Matlab implementation of the INST model (`protoanchor`).

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

**No response-set-size manipulation.** The manipulation is feedback-dependent context.
No master/restricted structure.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)

**Full raw data and model code deposited** — 412 files, 10.25 MB uncompressed, including
`readme.txt` files per experiment and a PDF preprint. Verified by listing the archive. The
readme warns the Matlab scripts "depend on various utilities and on the whole infrastructure
available on Alex Petrov's office computer" and will not run standalone; the data files are
the useful part.

GPL-licensed, with an explicit citation requirement.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Unusable for this project** — exemplary open data, but the number of response
categories is fixed, so there is no restriction to score. Recorded to close out the Petrov
branch and to note that this archive is *not* the Petrov & Anderson (2005) data, which is a
mistake easy to make from the ANCHOR page's cross-links.
