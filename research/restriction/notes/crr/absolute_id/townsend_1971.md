## Citation

Townsend, J. T. (1971). Theoretical analysis of an alphabetic confusion matrix.
*Perception & Psychophysics*, 9, 40-50. DOI 10.3758/BF03213026. (Companion: "Alphabetic
confusion: A test of models for individuals", *P&P*, 9, 449-454.)

## Domain and stimuli

Visual identification of the 26 uppercase letters, tachistoscopic.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

**No restriction — fixed 26-letter set.** The manipulation is presentation conditions,
not response set membership. Included only to record that Townsend's better-known 1971 letter
matrices are *not* the nested ones; the nested design is Townsend & Landon (1982), which is
the file to read.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)

Full 26x26 confusion matrices are printed, and are widely reused. No restricted-set
counterpart.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Unusable** for the restricted-response-set test — no restriction. Potentially useful as
a large master matrix for calibration if a 26-alternative case is ever wanted, but with no
matching restricted matrix it cannot serve as a held-out test.
