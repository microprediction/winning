## Stimuli and master response set

Speech messages in noise. The title promises confusion matrices explicitly. This is the long-form
laboratory report behind Egan (1957, *JASA* 29, 482-489) — same laboratory, same year, same
operating-characteristic framework, with "message repetition" as an additional manipulation not
visible in the journal abstract.

Master set size and vocabulary: unknown. Technical reports of this series routinely printed the full
matrices that the journal versions compressed, which is exactly why this document matters.
