# Eriksen & Hake (1955)

## Citation

Eriksen, C.W., & Hake, H.W. (1955). Absolute judgments as a function of stimulus range and
number of stimulus and response categories. *Journal of Experimental Psychology*, 49(5),
323–332. DOI 10.1037/h0044211. PMID 14367716. Johns Hopkins University, Baltimore, Md.
80 citations (Semantic Scholar).

An earlier APA-convention version exists: Eriksen, C.W., & Hake, H.W. (1954), same title,
PsycEXTRA 10.1037/e423932004-001.

## Domain and stimuli

Absolute judgment of **visual size** — squares of varying size. Non-speech, non-letter,
single-dimensional magnitude judgment. The **range** of the square sizes to be judged was
manipulated as well as the number of categories.

This is a classic of the information-transmission / channel-capacity literature (the Miller
"magical number seven" era), not of the CRR literature proper — it does not use Luce's or
Clarke's vocabulary. It earns a place here because its central manipulation is the one CRR
cares about: **the same stimuli judged with different numbers of response categories.**

Subject numbers, trial counts and the exact category counts used are not established — see
Access; only the *Psychological Abstracts* summary has been retrieved.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

The design crosses number of **stimulus** categories with number of **response** categories,
which is stronger than a pure nested-response-set manipulation and also more confounded.
Three regimes are distinguished in the result:

- **#responses = #stimuli** — the standard matched absolute-judgment case.
- **#responses > #stimuli** — surplus response alternatives available. Transmitted
  information is unaffected.
- **#responses < #stimuli** — the response set is genuinely **restricted relative to the
  stimulus set**, i.e. survivors must absorb the removed categories' mass. This is the CRR-
  relevant cell, and it is the one where performance degrades.

Note carefully what is *not* here: because the number of stimulus categories moves too, this
is not a clean nested-menu design over a fixed stimulus ensemble in the Clarke sense. To use
it as a CRR test you need the cells in which the stimulus ensemble is held fixed while only
the response categories are cut — the "response categories less than the number of stimuli
to be judged" condition. Whether those cells share a stimulus ensemble with a matched
full-response condition has to be checked in the paper itself.

The authors' own explanation of the effect is **anchor effects** — that the end stimuli
behave specially under the absolute method — and they explicitly deny that anchor effects
reduce to the mechanical truncation of responses at the ends of the scale. That is a
representation-changes-with-context claim, i.e. the same class of explanation that defeats
proportional renormalization.

## What numbers are printed (which tables, counts or proportions, per subject or pooled)

**Not established.** The retrievable summary reports only the information-theoretic dependent
variable, transmitted information (I_t), and the direction of its changes. Whether the
stimulus-response matrices behind those I_t values are printed cannot be determined without
the article; JEP papers of this era computing I_t often do print the underlying matrices for
at least the key conditions, but often report only the derived measures.

Do not assume matrices are present. Treat "prints a master confusion matrix plus restricted
response sets over the same stimuli" as **unverified** for this paper.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Needs library access, and check before investing.** Any university with the APA PsycNet /
PsycARTICLES back-file has it as a one-click PDF; JEP 1955 is fully digitized there. There is
no free route.

But temper expectations. Two things have to be true for this to be usable as a CRR dataset,
and neither is verified: (a) the stimulus-response matrices must actually be printed, not just
I_t; and (b) there must be a pair of conditions sharing one stimulus ensemble that differ only
in the number of available response categories. If the paper reports only transmitted
information — a plausible outcome — it is **unusable** for testing odds-ratio invariance,
because I_t is a scalar summary that discards exactly the off-diagonal structure the test
needs. It would then survive only as a citation for the qualitative fact that cutting the
response set below the stimulus set costs discrimination, plus the anchor-effect explanation.

Recommended order: read it, decide in five minutes from the tables, and do not budget more
than that until the tables are seen.

## What the authors concluded, quoted verbatim where possible

The article itself has not been read, so nothing from the authors' own prose can be quoted.

What follows is the full *Psychological Abstracts* (1956, Vol. 29, No. 1, abstract no. 253)
summary, verbatim from the OCR, including the OCR's own garbling — "the number of r yer
categories" is the scan mangling "the number of response categories", and the title as
printed there drops the word "response":

> "253. Eriksen, Charles W., & Hake, Harold W. (Johns Hopkins U., Baltimore, Md.) Absolute
> judgments as a function of stimulus range and number of stimulus and categories. J. exp.
> Psychol., 1955, 49, 323-332.—Increasing the size of the squares (range) to be judged
> increased I, (transmitted information). I, remained constant as the number of stimulus and
> response categories was increased provided the number of r yer categories equalled or
> exceeded the number of stimulus categories. A loss in discrimination resulted when the
> number of response categories was less than the number of stimuli to be judged. Further
> analysis showed that these effects can be attributed to the anchor effects characteristic
> of the absolute method: at the same time these anchor effects cannot be completely
> accounted for on the basis of the artificial curtailment of responses to the end stimuli
> —J. Arbit."

Two readings for this project. First, "I_t remained constant as the number of stimulus and
response categories was increased provided the number of response categories equalled or
exceeded the number of stimulus categories" is a *pro*-invariance result: adding unused
alternatives costs nothing, which is what any renormalization account predicts. Second, "A
loss in discrimination resulted when the number of response categories was less than the
number of stimuli to be judged" is the anti-invariance half: shrinking the menu below the
stimulus ensemble does not merely reallocate mass proportionally, it degrades the
discrimination itself. And the authors refuse the deflationary explanation — the anchor
effects "cannot be completely accounted for on the basis of the artificial curtailment of
responses to the end stimuli."
