# Rich (1971)

## Citation

Rich, R.F. (1971). Constant ratio rule for confusion matrices from short-term memory
experiments. *British Journal of Psychology*, 62(1), 27–35.
DOI 10.1111/j.2044-8295.1971.tb02007.x. Robert F. Rich, Department of Psychology, Monash
University, Clayton, Victoria, Australia.

**This is the only paper found in the entire sweep whose title is an explicit CRR test on
short-term memory confusion matrices.** It is the highest-priority acquisition target in the
memory domain and I could not obtain its text.

## Domain and stimuli

Short-term memory confusion matrices. The stimulus class is **not established** — no
abstract could be retrieved from any source. Given the date, the venue, and the STM
confusion-matrix literature Rich would have been working from (Conrad's acoustic-confusion
programme, Wickelgren, Hodge's CRR reports), consonant letters or digits are the most likely
stimuli, which would put it in the letter/digit family rather than a fully non-letter domain.
Treat the domain as unverified until the paper is read.

Only 4 citations recorded in Semantic Scholar, which is why no secondary source describes it.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)

Not established. The title asserts a CRR test on confusion matrices, and a CRR test requires
at minimum a master matrix plus one submatrix over the same stimuli, so nested response sets
are near-certain in form — but whether the restriction was imposed on the response set, or
the submatrices were merely extracted arithmetically from one master matrix (Clarke's own
weaker "internal" method, which is not a real menu manipulation and cannot test
context-independence), is exactly the thing that has to be checked on reading. Clarke (1957)
did both; many of the follow-ups did only the arithmetic version.

Flag this: if Rich only partitions a single master matrix, the paper is of limited use to
this project regardless of its conclusion, because no alternative was ever removed from the
subject's menu.

## What numbers are printed (which tables, counts or proportions, per subject or pooled)

Unknown. Not retrieved. A nine-page 1971 *BJP* paper on confusion matrices would normally
print at least one master matrix as frequencies or proportions plus the derived and observed
submatrices, but this is an expectation only.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)

**Needs library access.** There is no open copy anywhere: Wiley paywalls it, there is no
green deposit, Europe PMC does not cover it, and the one free surrogate (the 1971
*Psychological Abstracts* volume on the Internet Archive) is behind IA's print-disabled
restriction, which is why even the abstract is unavailable. Monash University's own
repository has nothing.

Route to get it, in order: (1) any institution with the Wiley *British Journal of Psychology*
back-file, which is the whole run from 1904 — a single PDF download; (2) interlibrary loan;
(3) an IA print-disabled account, which would unlock
`sim_psychological-abstracts_1971-07_46_1` and at least yield the abstract, enough to decide
whether the full paper is worth the ILL.

Worth the effort: **yes, highest priority in the memory domain.** It is the only titled CRR
test on STM confusion matrices in the literature, and even a negative outcome (arithmetic
submatrices only, no menu manipulation) is worth knowing so the gap can be stated honestly
rather than left as an unchecked citation.

## What the authors concluded, quoted verbatim where possible

**No text of any kind was obtained** — not the abstract, not a secondary description. Nothing
can be quoted, and nothing should be asserted about Rich's conclusion. The paper's title
should not be read as endorsing the rule: titles in this literature run both ways (compare
Bensemann et al. 2015, "Steady-state choice between four alternatives *obeys* the
constant-ratio rule" against Elliffe & Davison 2010, "Four-alternative choice *violates* the
constant-ratio rule"), and Rich's title is neutral on the outcome.
