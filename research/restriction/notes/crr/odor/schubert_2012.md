# Schubert et al. 2012 — Beaver Dam Offspring Study: a 20-alternative picture array, inaccessible

## Citation
Schubert CR, Cruickshanks KJ, Fischer ME, Huang GH, Klein BE, Klein R, Pankow JS, Nondahl DM.
"Olfactory impairment in an adult population: the Beaver Dam Offspring Study." *Chemical Senses*
2012;37(4):325–334. doi:10.1093/chemse/bjr102. PMC3325763. (Verified via Europe PMC core record.)

## Domain and stimuli
Olfaction, population-based cohort of adults (Beaver Dam, Wisconsin). **San Diego Odor Identification
Test (SDOIT)**: 8 odorants presented in jars.

## Master response set and restricted response sets (nested, overlapping, or a relabelling)
**A 20-alternative response array — by far the largest response set found in any olfactory
identification study.** Respondents point at a picture board showing "all the odorants plus 12
distracters", i.e. the 8 targets plus 12 additional pictured items = **20 alternatives, identical for
every trial**.

Structurally this is the most interesting fixed menu in the directory: one large master set of 20
shared across all 8 odors, so every trial is a choice from the *same* alternative universe with only
the stimulus varying. That is precisely the configuration in which cross-item choice structure is
interpretable, because the menu is genuinely held constant. Had this data been public it would be the
single best olfactory dataset for choice-model work.

No restriction condition — the 20-item board is used on every trial.

## What numbers are printed or deposited (which tables/files, counts or proportions, per subject or pooled)
**Pooled prevalence only in the paper.** Whether per-trial pointed-at responses were retained in the
study database is **undeterminable from public sources**.

## Access (a DIRECT url you fetched; open, paywalled, or Wayback-only)
Paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC3325763/ — **open access**.
Data: **no public route exists.** `boss.wisc.edu` does not resolve; there is **no BioLINCC entry** and
**no dbGaP record** for the Beaver Dam Offspring Study. Collaboration with the Wisconsin investigators
is the only path.

## Usability verdict (usable now / needs digitizing / needs library access / unusable, and why)
**Unusable — no data access route at all.** Nothing to digitize (the paper prints prevalence, not choice
distributions), and unlike the restricted-but-requestable datasets here, there is no application form to
submit: no repository, no dead study website, no dbGaP.

Logged because the 20-alternative SDOIT format is tantalizing and will keep attracting attention. If a
collaboration were ever feasible, the first question to ask is whether the pointed-at picture was
recorded per trial or only scored correct/incorrect — the SDOIT is often scored the latter way, in which
case even access would yield nothing.

## What the authors concluded, quoted verbatim where possible
Not verified verbatim. The paper reports the **prevalence and risk-factor correlates of olfactory
impairment** in a middle-aged general adult population, with impairment increasing by age and being more
common in men. Response-set structure is not discussed; the 20-picture board is described only as the
administration method.
