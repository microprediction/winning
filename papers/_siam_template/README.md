# SIAM article template (not a paper)

The stock SIAM distribution: `siamart171218.cls`, `siamplain.bst`, the
example articles `ex_*.tex`, and the figures those examples reference.
Nothing in this repository builds against it; `papers/siam2021` holds
the reproduction material for the published SIAM paper, and every
current manuscript uses the `article` class.

Kept because it is what the 2021 submission was built with. The
underscore prefix marks it as not a manuscript folder, so the
one-folder-per-paper rule in `../README.md` still reads cleanly.
